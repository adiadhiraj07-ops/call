# Call

One-tap call page for boards that run inside claude.ai, where phone (`tel:`) links are blocked.

Link to `https://adiadhiraj07-ops.github.io/call/#+919876543210`: the page opens the phone app with that number, with a big "Call now" button in case the phone asks first.

The number goes after the `#`, which browsers never send to the server, so GitHub never sees it. The page loads nothing from other sites and has no analytics.
